# RIVER RP

[Скачать River RP Лаунчер для Windows 10–11 x64](https://github.com/mrpufok/river-rp-releases/releases/download/river-platform-v0.2.4/RIVER-Platform-Setup.exe)

1. Установите лаунчер в выбранную папку.
2. Откройте **River RP Лаунчер** и нажмите **Скачать игру**.
3. После проверки файлов нажмите **Играть** и выберите DON.

Если RIVER уже установлен, откройте существующий ярлык и обновите лаунчер. Если обновление не начинается, закройте лаунчер и запустите установщик выше, выбрав папку существующей установки.

[Файлы релиза, лицензии и исходный код GPL-клиента](https://github.com/mrpufok/river-rp-releases/releases/tag/river-platform-v0.2.3)
