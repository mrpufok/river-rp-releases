# RIVER RP

[Скачать установщик](https://github.com/mrpufok/river-rp-releases/releases/latest/download/RiverRP-Launcher-Setup.exe)

Обновлённый River RP Лаунчер для Windows 10–11 x64. Локальный сервер Addon.

[Скачать установщик](https://github.com/mrpufok/river-rp-releases/releases/latest/download/RiverRP-Launcher-Setup.exe)

- Новый интерфейс с тематическим фоном, компактными настройками и иконкой проекта.
- Ярлыки «River RP Лаунчер» на рабочем столе и в папке установки.
- При первом запуске игра устанавливается рядом с лаунчером, путь можно изменить.
- Обязательное обновление лаунчера блокирует загрузку и запуск игры; после установки приложение открывается снова.
- Запуск вместе с Windows включён по умолчанию; автоскачивание обновлений игры включается только вручную.
- Единый EXE со встроенной средой исполнения: устанавливать .NET отдельно не требуется.

Маленький онлайн-установщик скачивает примерно 63 МиБ файлов приложения и проверяет SHA-256. GTA и MTA скачиваются отдельно кнопкой «Скачать» после проверки выбранной папки.

Игровой комплект сохранён с предыдущего выпуска. Его архивы находятся в предыдущем релизе, лаунчер получает их автоматически по подписанному манифесту.

Сервер Addon должен работать на том же компьютере. Публичное подключение из интернета пока не настроено. Лицензии компонентов находятся в папке Licenses установленного лаунчера.
