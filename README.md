# RIVER RP

[Скачать установщик](https://github.com/mrpufok/river-rp-releases/releases/latest/download/RiverRP-Launcher-Setup.exe)

Локальная проверка RIVER RP с сервером Addon на этом компьютере.

Скачайте RiverRP-Launcher-Setup.exe, установите лаунчер и выберите общую папку игры. Нажмите «Проверить», затем «Скачать». После установки GTA и MTA в подпапки выбранного каталога появится «Играть».

- Более светлый зелёный интерфейс и скруглённые края.
- Addon выбирается автоматически, статус и число игроков запрашиваются напрямую у сервера.
- Сжатые игровые пакеты, проверка подписи и целостности, докачка после обрыва.
- Обновление лаунчера проверяется автоматически при запуске.
- При первом запуске из новой папки Windows запросит разрешение на настройку пути GTA для MTA.

Для этой локальной проверки сервер должен быть запущен на том же компьютере. Подключение из интернета в этой сборке не настроено.

Служебные файлы с длинными именами скачивает сам лаунчер; вручную их открывать не нужно. Лицензии сторонних компонентов находятся в ThirdPartyNotices.zip и в папке Licenses установленного лаунчера.
